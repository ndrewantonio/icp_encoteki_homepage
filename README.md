This is Encoteki Homepage create with Next.js

## Getting Started

Node version required minimum 18.17.0

First Install

```bash
yarn install
```

To run the development server:

```bash
yarn dev
```

To build for production:

```bash
yarn build
```

To create static folder to build:

```bash
add this on next.config.mjs

const nextConfig = {
  output: 'export'
}
```
